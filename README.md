# Nest

A calm, local-first baby tracker. Feeding, diapers, food, medication, growth, milestones, and baths — all stored on your phone.

**Live site:** https://nbaldwin0.github.io/nest/

Your logs never go to GitHub. This repo only hosts the app code.

## Add to iPhone Home Screen

1. Open the live site in **Safari**.
2. Tap Share → **Add to Home Screen**.
3. Leave **Open as Web App** on.
4. Name it Nest → Add.

Open Nest now and then so iOS does not clear unused storage. Export from the Child tab if you want a backup.
